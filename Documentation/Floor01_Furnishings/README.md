# 已讨论通过的四处室内布置

本轮仅在本地实现，等待用户检查；没有提交或 push。

- N02：4组弧形拼桌，每组4席；展示屏、白板及低资料柜。
- S01：8个矮隔板教师工位，以到顶玻璃墙和默认关闭的玻璃门围合，步行靠近自动开门；玻璃外为共同开放的4人讨论桌和沙发休息区，两者之间没有隔墙。
- S02：从南侧入口进入后，右侧小接待台，左侧轻巧沙发；学院标识位于沙发上方，公告栏位于旁边靠入口处。中央进出路线保持畅通。
- S03：4个行政工位、封闭文件柜、常用资料书架与共享文印角。

其余房间继续保留上一阶段空结构，尚未决定家具。外轮廓、外墙门窗、两座楼梯和两条2.4m公共走廊保持既有结构。

在 Unity 打开 `Assets/Scenes/JEI_Floor01_Structure.unity`。Play后拖拽环绕、滚轮缩放，0总览、1分组教室、2教师办公、3接待、4行政资料；Tab切换步行，WASD移动，Esc释放鼠标。

代码入口：`Tools/JEI/Interiors/Apply Agreed Furnishings`。此操作只重建带生成标记的室内布置组，结构生成器与本工具分别保留；若重建结构，请再次应用室内布置。

所有自建桌椅网格、材质和地面纹理保存为项目资源，非临时对象。玻璃墙表现空间分隔，未进行声学仿真。验证与三维预览位于本目录。
